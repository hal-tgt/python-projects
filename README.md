# Python Projects

Pythonで作った学習・実践プロジェクト集です。

## プロジェクト一覧

### 🌤 AI天気Discord Bot (ai_bot.py)
- Discord上で天気情報を自動返信
- Open-Meteo APIで天気データを取得
- Groq AIで自然な会話が可能

### 🤖 Discord Bot (discord_bot.py)
- 「天気」コマンドで東京の天気を表示

### 📊 売上分析 (sales.py)
- CSVデータを読み込んで集計
- matplotlibでグラフ化

### 🌐 Webスクレイピング (scraping.py)
- BeautifulSoupでWebサイトからデータ収集
- Excelに自動保存

### 🌡 天気予報取得 (weather.py)
- Open-Meteo APIからリアルタイム天気取得

## 使用技術
- Python 3.14
- discord.py / Groq API / pandas / matplotlib / BeautifulSoup
